# Cryptocurrency marks

These SVGs are served locally so the interface does not depend on an image CDN at runtime. The UI labels each mark with its asset name and falls back to the ticker text if a file is unavailable.

- `bitcoin.svg`, `bnb.svg`, `ethereum.svg`, `polygon.svg`, `solana.svg`, and `usdt.svg`: Simple Icons brand SVGs from [simpleicons.org](https://simpleicons.org/) (`bitcoin`, `bnbchain`, `ethereum`, `polygon`, `solana`, and `tether`). Solana uses its published purple and green brand colors for contrast.
- `trx.svg`: the TRON ticker mark from [`cryptocurrency-icons` 0.18.1](https://github.com/spothq/cryptocurrency-icons/tree/master/svg/color).

The marks identify currencies and networks; they do not imply endorsement. Review each brand's current usage terms before a public commercial launch. Official brand references: [Solana](https://solana.com/branding) and [TRON](https://tron.network/resources/?lng=en).
